## 🔍 Caso de estudio: Diseño de la base de datos de Alke Wallet

**Breve descripción de la actividad**
Diseñar y construir desde cero la base de datos de una billetera virtual, capaz de registrar usuarios, monedas y transacciones de forma segura y consistente.

**Desafío principal**
Garantizar que los movimientos de dinero fueran confiables: que una operación se guardara completa o no se guardara, sin dejar saldos inconsistentes. Además, yo partía sin experiencia previa en bases de datos y tuve que instalar y configurar MySQL desde cero, resolviendo un conflicto con la contraseña de root.

**Solución propuesta**
- Modelé tres tablas relacionadas (`usuario`, `moneda`, `transaccion`) y las normalicé para evitar datos repetidos.
- Ejecuté los movimientos dentro de **transacciones ACID** (todo o nada), con confirmación (COMMIT) o reversión (ROLLBACK) si algo fallaba.
- Escribí las consultas requeridas para revisar saldos y movimientos.
- Documenté el diseño con un diagrama entidad-relación.

**Herramienta técnica utilizada**
MySQL y MySQL Workbench para modelar y probar; SQL para crear tablas y consultas; Git y GitHub para versionar y publicar.

**Principales aprendizajes**
- Cómo se diseña un modelo relacional y por qué importa la normalización.
- Qué significa ACID y cómo las transacciones protegen la integridad de los datos.
- A instalar, configurar y depurar un motor de base de datos por mi cuenta.
- A documentar mi trabajo para que otras personas lo entiendan.

**Métricas de impacto logradas**
- 3 tablas relacionadas con datos normalizados.
- Movimientos de dinero ejecutados como transacciones atómicas (todo o nada).
- Consultas solicitadas resueltas y probadas en MySQL Workbench.
- Proyecto documentado (diagrama ER y explicación) y publicado en GitHub.

**Habilidades técnicas aplicadas**
Modelado relacional, normalización, SQL (DDL y DML), manejo de transacciones, consultas, instalación y configuración de MySQL, control de versiones con Git.

**¿Por qué elegí este proyecto para mi portafolio?**
Porque refleja mi crecimiento técnico: empecé sin saber de bases de datos y terminé diseñando un sistema donde la integridad del dinero es crítica. Además, es la base de datos que respalda mi aplicación web Alke Wallet, por lo que muestra que puedo conectar el frontend con los datos.
